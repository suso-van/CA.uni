# VHDL Digital Logic Design Programs

This repository contains a collection of fundamental VHDL implementations developed as part of Digital Electronics and VLSI laboratory exercises. The programs demonstrate the application of **Behavioral**, **Dataflow**, and **Structural** modeling techniques for designing and implementing basic combinational logic circuits.

## Programs Included

* XOR Gate using If-Else Statement
* XNOR Gate using If-Else Statement
* Full Adder using Dataflow Modeling
* 4×1 Multiplexer using Case Statement
* AND Gate using Dataflow Modeling
* OR Gate using Dataflow Modeling
* Inverter (NOT Gate) using Dataflow Modeling
* 8-to-3 Encoder using Dataflow Modeling
* 3-to-8 Decoder using Case Statement
* 4×1 Multiplexer using 2×1 Multiplexers (Structural Modeling)
* NAND Gate using Dataflow Modeling
* 4-to-2 Encoder
* 2-to-4 Decoder

## Overview

The objective of this repository is to provide simple, well-structured VHDL implementations of commonly used digital logic circuits. These programs are intended for academic learning, laboratory experiments, simulation, and practice with hardware description language (VHDL).

Each implementation follows the modeling technique specified in the corresponding experiment, making the repository a useful reference for students studying Digital Logic Design, VLSI Design, and FPGA-based system development.
